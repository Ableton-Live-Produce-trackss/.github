## 🚀 Key Features

- **Session View** — Launch clips and scenes for improvisation and live arrangements.
- **Arrangement View** — Build a complete song within a linear timeline.
- **Audio Warping** — Align rhythmic material and recorded phrases to project tempo.
- **Drum Rack** — Arrange individual drum sounds across playable pads.
- **MIDI Editing** — Refine notes, expression and velocity within MIDI clips.
- **Device Chains** — Combine instruments, audio processors and effect routing.
